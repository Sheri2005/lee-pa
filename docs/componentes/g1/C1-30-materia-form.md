# C1-30: Formulario de Materia (`app-materia-form`)

## Descripción General
Componente hijo de tipo formulario (Reactive Forms) diseñado para la creación y edición de los datos correspondientes a una materia institucional.

## Detalles Técnicos
- **Selector**: `app-materia-form`
- **Clase**: `MateriaFormComponent`
- **Tipo**: Hijo (formulario)
- **Grupo Dueño**: G1 · Gestión
- **Responsable**: Matías Sánchez
- **Ruta**: `—`

## Integración de Servicios
Utiliza validaciones reactivas y se comunica con el servicio de materias para persistir cambios o altas en el sistema.
