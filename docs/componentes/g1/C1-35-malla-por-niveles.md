# C1-31: Selector de Materia (`app-selector-materia`)

## Descripción General
Componente selector de dominio reutilizable que permite buscar, filtrar y seleccionar una materia específica dentro de los flujos académicos.

## Detalles Técnicos
- **Selector**: `app-selector-materia`
- **Clase**: `SelectorMateriaComponent`
- **Tipo**: Selector de dominio
- **Grupo Dueño**: G1 · Gestión
- **Responsable**: Matías Sánchez
- **Ruta**: `—`

## Integración de Servicios
Consume el servicio de materias para poblar de forma dinámica las opciones disponibles y emitir la selección correspondiente.
