# Reportería · Grupo 5

Responsabilidad: aprobaciones, notificaciones, reportería y exportación al SIAC 1.0.

Integrantes: Lima, Calderón, Rea y Guamán.

Ubica aquí los componentes, servicios, modelos y rutas propios de este módulo. Usa Angular y Tailwind CSS.

## Componente compartido del Grupo 5

`app-campo-codigo-siac` es un control standalone propiedad del Grupo 5, ubicado en `src/app/shared/components/campo-codigo-siac` para que Gestión y Horarios puedan reutilizarlo. Consulta el [README del componente](../../app/shared/components/campo-codigo-siac/README.md) para el uso con formularios reactivos y el contrato del adaptador de unicidad.

`app-grafico` es el componente standalone compartido para reportes de barras, pastel y líneas. Consulta el [README del gráfico](../../app/shared/components/grafico/README.md) para el contrato de datos y su uso desde las páginas de reportes.
